# Gate 14 Structured Attribution and Thesis Lifecycle

The structured layer is canonical; narrative text is only a deterministic,
cautious summary of stored evidence. Each selected Top-900 ticker receives
primary, supporting, contradicting, context-only, and missing evidence arrays,
plus confidence, readiness, coverage, freshness, lineage, frozen historical
metadata, and prospective confirmation state.

The layer consumes only a successful same-date prospective capture. If either
the Top-900 snapshot or the original Gate-14 prospective signal manifest is not
CAPTURED, it writes no structured rows.

Events and disclosures store three separate facts: occurrence, unassessed
interpretation, and predictive validity not established. Ownership residuals
remain explicitly labelled as upper bounds rather than official free float.

Theses are opened only for tickers with at least one active frozen candidate.
Every initial component percentile is stored before outcomes mature. Later
same-date prospective observations produce a driver-change ledger and one of:
STRENGTHENING, INTACT, WEAKENING, BROKEN, EXPIRED, or INVALID_DATA. A stored
20-session price floor is an explicit structural invalidation. All outputs are
shadow-only and cannot write production score, rank, action, or execution state.
